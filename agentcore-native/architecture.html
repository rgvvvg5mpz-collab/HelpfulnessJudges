AgentCore calls the model. No Lambda, no SDK, no code you run — and no control over the prompt's output contract, the sampling, or the verdict shape. This is the simplicity-first path.

The decision in one line. This path is right if you want judges running this week with no infrastructure and can accept directional scores. It is wrong if the numbers must be comparable to the validated anchor set — because the prompts are no longer the prompts that were validated, and no amount of care in transform.py changes that.

What the transform actually does

auditable, not implicit

Run native-judges diff to see it per judge. For every rubric it removes the ## How to score preamble section and the rubric's own ## Score section — both prescribe an output contract AgentCore forbids you from writing — and rewrites 6–13 references to transcript markers that do not exist here ([BEGIN TRANSCRIPT], >>> TARGET, [tool trace: …]) into the closed placeholder vocabulary.

It then appends two sections the rubrics never needed: a compact reasoning contract (CHK C1=y C2=n … | TRIG y | BL -) and a rating section whose wording matches the ratingScale labels exactly, so the model is not being asked for two different vocabularies.
