Deployment paths

The same ten judges, three places to run them. Each folder is standalone — its own copy of the rubrics, its own docs, tests and labelled data. They are different instruments, not one instrument at three quality levels; averaging their scores is not defensible.

agentcore-integration

Bedrock AgentCore · code-based Lambda evaluator

Preserves the suite as validated: rubrics unchanged, JSON schema enforced, reasoning effort set, prompt caching, k=5 median. Choose it when the numbers must stay comparable to the anchor set.

arize-integration

Arize AX · template evaluators, hosted by Arize

Arize runs the prompt. One scoring file is rewritten; the rest is byte-identical. Gives up reasoning effort entirely — graded fatal in its own docs. Choose it when Arize is already the system of record.

agentcore-native

Bedrock AgentCore · native llmAsAJudge, no infrastructure

Every rubric is rewritten at deploy time to fit the platform's forced output contract. Gives up the most, needs no infrastructure at all, and is honest that the prompts which run are not the prompts that were validated.
